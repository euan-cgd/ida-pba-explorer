Equivalent CPR change

Two changes have the same effect when they give the country the same raw score (CPR3 × GNI per capita−0.125), because nothing else in the formula changes. So the equivalent CPR change is CPR × (multiplierGNI exponent / CPR exponent − 1). This does not hold if the GNI change moves the country across a cutoff.
